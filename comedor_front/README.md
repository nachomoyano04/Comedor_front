# Sistema de Comedor Escolar — Aplicación Frontend

Para instrucciones completas de instalación, configuración de variables de entorno y despliegue, consulte el [README principal del repositorio](../README.md).

### Comandos Rápidos

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build
```
